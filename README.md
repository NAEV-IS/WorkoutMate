# WorkoutMate — Fitness Management App

WorkoutMate es una aplicacion multiplataforma disenada para digitalizar la gestion, asignacion y seguimiento de rutinas en gimnasios independientes. Fue desarrollada como proyecto integrador para la titulacion de Analista en Software.

El foco del proyecto estuvo puesto en dos pilares: una estructura de codigo solida y escalable, y una experiencia de usuario (UX/UI) fluida e intuitiva tanto en Android como en iOS.

## Caracteristicas Principales
* Gestion de Rutinas: Creacion y seguimiento de entrenamientos personalizados.
* Compartir mediante QR: Funcionalidad nativa para compartir rutinas a traves de codigos QR y enlaces unicos.
* Multiplataforma: Experiencia nativa optimizada para iOS y Android.

## Arquitectura y Documentacion
El proyecto fue estructurado bajo los principios de Clean Architecture, separando estrictamente las capas de presentacion, dominio y datos para garantizar la mantenibilidad y facilidad de testing.
* Modelado completo mediante diagramas UML (Casos de uso, Clases, Secuencia).
* Definicion de historias de usuario y matriz de trazabilidad.

## Tecnologias Utilizadas
* Frontend/Mobile: Flutter y Dart
* Base de Datos: MySQL
* Arquitectura: Clean Architecture
* Control de Versiones: Git
